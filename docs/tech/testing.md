# Тестирование

| Уровень | Инструменты | Что проверяется | Покрытие / объём |
|---|---|---|---|
| Модульные тесты | pytest, Vitest | бизнес-правила переходов статусов, расчёт метрик | 82 % строк кода |
| Интеграционные | pytest + Testcontainers | работа сервисов с PostgreSQL, RabbitMQ, вебхуками Git | 140 сценариев |
| Контрактные | Pact | совместимость API между сервисами | 36 контрактов |
| E2E | Playwright | ключевые пути: задача → ревью → релиз | 24 сценария |
| Нагрузочные | k6 | 500 одновременных пользователей, 200 вебхуков/с | перед каждым мажорным релизом |

## Критерии выпуска релиза

1. Все автотесты в пайплайне пройдены.
2. Нет открытых дефектов критичности «блокер» и «критический».
3. Приёмочное тестирование QA подтверждено в карточке релиза.
4. Время ответа API под нагрузкой – не более 300 мс (95-й процентиль).
