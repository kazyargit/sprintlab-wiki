# Программные и аппаратные требования

## Серверная часть (продуктив)

| Компонент | Версия / параметры | Назначение |
|---|---|---|
| Kubernetes | 1.29+, 3 рабочих узла по 8 vCPU / 32 ГБ ОЗУ | оркестрация сервисов |
| PostgreSQL | 15, SSD 500 ГБ, репликация | основная база данных |
| Redis | 7 | кэш, очереди уведомлений, сессии |
| RabbitMQ | 3.13 | шина событий Git и CI |
| MinIO (S3) | – | артефакты сборок, вложения |
| Prometheus + Grafana | – | метрики и мониторинг |

## Среда разработки

- Python 3.12, FastAPI; Node.js 20, React 18, TypeScript;
- Docker Desktop 4.x, docker compose для локального запуска;
- Git 2.40+, доступ к GitHub.

## Клиентская часть

- браузеры: Chrome, Edge, Firefox, Safari – две последние версии;
- минимальное разрешение экрана – 1280 × 720;
- интернет-соединение от 5 Мбит/с.
