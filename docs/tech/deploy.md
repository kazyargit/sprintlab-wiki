# Развёртывание

| Окружение | Назначение | Как обновляется |
|---|---|---|
| dev | разработка и отладка | автоматически при слиянии в ветку `develop` |
| stage | приёмочное тестирование | по тегу `rc-*` |
| prod | работа клиентов | по тегу релиза `v*` после приёмки QA |

Пайплайн поставки: сборка образов Docker → модульные и интеграционные тесты → публикация в реестр → развёртывание на stage → E2E-тесты → ручное подтверждение → развёртывание на prod по схеме blue-green.

Резервное копирование базы данных – ежедневно, хранение 30 дней; восстановление проверяется раз в месяц.
