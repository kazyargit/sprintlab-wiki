# Безопасность

- **Аутентификация** – вход через GitHub OAuth или по почте и паролю; обязательная двухфакторная аутентификация для владельцев организаций.
- **Токены** – короткоживущие JWT (15 минут) и refresh-токены с отзывом при выходе.
- **Права доступа** – ролевая модель: владелец, руководитель проекта, разработчик, тестировщик, заказчик (только чтение своих задач).
- **Секреты интеграций** – ключи GitHub и CI хранятся в зашифрованном хранилище, в интерфейсе не показываются.
- **Проверка вебхуков** – каждое событие от GitHub проверяется по подписи HMAC-SHA256.
- **Шифрование** – TLS 1.3 для всех соединений, шифрование резервных копий AES-256.
- **Журнал аудита** – фиксируются входы, изменения прав и удаление данных; хранение 1 год.
- **Защита от уязвимостей** – статический анализ кода и проверка зависимостей в каждом пайплайне.
