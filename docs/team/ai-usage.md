# Применение ИИ при создании Wiki

При подготовке Wiki использовалась языковая модель **Kimi K3**. Модель предлагала черновики, окончательные формулировки и числа выбирались командой.

| Задача | Сокращённый промпт | Как использован результат |
|---|---|---|
| Слоган и описание продукта | «Предложи 5 вариантов слогана и краткое описание платформы управления процессом разработки ПО: проблема, пользователи, особенности» | выбран и сокращён один слоган, описание переписано под продукт |
| Главный KPI и метрики | «Какой главный KPI выбрать для платформы управления разработкой и какие вспомогательные метрики вынести отдельно?» | выбран Lead Time for Changes, остальные метрики DORA – на вложенную страницу |
| Схема базы данных | «Составь перечень сущностей и связей базы данных для платформы: проекты, спринты, задачи, коммиты, сборки, релизы» | сущности сверены с архитектурой, по ним построена ER-диаграмма |
| Раздел безопасности | «Какие меры безопасности описать для SaaS-платформы разработки с интеграцией GitHub?» | список сокращён до мер, реально заложенных в продукт |
